shojin 精進

Sustained, diligent effort toward improvement. Investigations into whether and how AI agents improve themselves.

Findings

  • Claude Code self-improved on business workflows through conversation, not memories — told only to get better, an agent raised held-out success from 34% to 48% and built itself a knowledge base along the way. The knowledge base was not the mechanism.

The program

  • Pre-registrations and studies: designs frozen by merge, replication packages that reproduce every published number.
  • hgym: the evaluation harness the studies run on. Its core property: a run never reports a result that is wrong while looking correct.
  • shojin on PyPI: the program's tooling (in preparation).
